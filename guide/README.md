# The Colibri guide

- [Tutorial](tutorial.md): learn the language by building a word counter, a tested package and an
  HTTP service.
- [Language tour](tour.md): one short section for each feature, for programmers who know other
  languages.
- [Built-in types and functions](builtins.md): `str`, `List`, `Map`, `Set`, numbers, `Result`, and
  the functions that need no `import`.
- [Debugging](debugging.md): breakpoints, stepping, coroutines as threads and hot reload with
  `colibri debug`.
- [Rust bindings](rust-bindings.md): packages that call Rust crates, and the commands that build
  and run them.
- [Standard library reference](std/README.md): one generated page for each module.

Colibri is early and pre-release. The pages describe what works today, and mark what is planned.
Every sample in the guide is checked by the project's tests, and the ones that show their output
are run.
